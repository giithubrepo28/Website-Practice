# NovaWorks Studio — Business Website Practice

A responsive one-page business website built with **HTML, CSS, and JavaScript**. This is a learning project for the `Website-Practice` repository.

## Preview

Open [index.html](./index.html) in your browser, or enable GitHub Pages to publish the site online.

## What's included?

- Responsive navigation with a mobile menu
- Hero section and abstract CSS artwork
- Services, about, and process sections
- Contact form front-end interaction
- Accessibility basics, semantic HTML, and reduced-motion support
- Responsive layouts for mobile and desktop

## Run locally

1. Download or clone this repository.
2. Open the folder in your code editor.
3. Open `index.html` in a browser. For a smoother workflow, use the Live Server extension in VS Code.

## Beginner practice checklist

- [ ] Change the brand name from NovaWorks to your own idea.
- [ ] Update the services to match a real business.
- [ ] Change the colors in the `:root` section at the top of `style.css`.
- [ ] Edit the hero heading and description in `index.html`.
- [ ] Test the mobile menu on a narrow screen.
- [ ] Add a real form service or backend before collecting real customer messages.
- [ ] Publish with GitHub Pages.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

## Important note

The contact form is a front-end demo only. It does not send or store messages. Connect a trusted form service or your own backend before using it for real customers.
